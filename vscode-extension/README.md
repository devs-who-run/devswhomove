# Devs Who Move: Coding Movement Nudges

Suggests a walk after sustained editing in a focused VS Code window. Reminders do not log exercise. After completing a walk, use **Devs Who Move: Log a Completed Walk**, enter its duration, and confirm the public upload.

Create an agent token with `activities:write` in [Devs Who Move](https://devswhorun.dev), then use **Devs Who Move: Set Agent Token**. The token is stored in VS Code secret storage. Agent-created activities are public; a private GitHub profile still hides its activities from others, and AT Protocol records are public.

Settings control the reminder interval, idle reset, and server origin. See the [repository documentation](https://github.com/devs-who-run/devswhomove#vs-code-movement-nudges) for installation, privacy, and usage details.
